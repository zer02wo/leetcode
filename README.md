# leetcode

Repository for solutions to leetcode questions. Originally dictated by following [leetle.app](https://leetle.app/) - a Wordle-like for LeetCode,
but has since shifted to be dictated by other online resources.

These solutions will by no means be optimal, and will likely contain a lot of (unnecessary) comments detailing my approach/thinking process.
This is a learning resource for myself, you will probably find others have more thorough/complete explanations if you are also looking to learn.

Solutions will likely be in JavaScript. Problem number will be included at the start of the file name for easier browsing.
Leetle-specific problems that could not be linked to a Leetcode problem have been prefixed with `L-` before the problem number.

Each solution includes a link to the problem (or date/archive in the case of Leetle) for easy identification.
I have included "tags" for problem types at the top of files which may assist in searching for something specific.
