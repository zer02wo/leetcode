# leetcode

Repository for solutions to leetcode questions. Largely dictated by following [leetle.app](https://leetle.app/) - a Wordle-like for LeetCode

These solutions will by no means be optimal, and will likely contain a lot of (unnecessary) comments detailing my approach/thinking process.
This is a learning resource for myself, you will probably find others have more thorough/complete explanations if you are also looking to learn.

Solutions will likely be in JavaScript. Problem number will be included at the start of the file name for easier browsing.
